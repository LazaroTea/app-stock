# App de stock del vivero

Control de stock de árboles nativos de Argentina, en dos versiones:

| Carpeta | Versión | Datos |
|---|---|---|
| [`app-stock/`](app-stock/) | Google Sheets + Apps Script. Se usa desde la compu y el celu con un link. | Planilla de Google |
| [`app-stock-next/`](app-stock-next/) | Next.js. Corre en una computadora. | Archivo JSON con datos inventados |

Las dos tienen las mismas pantallas (Stock, Cargar, Últimos) y las mismas reglas: stock por especie y tamaño,
aviso de stock mínimo, entradas, salidas y ajustes.

Cada carpeta tiene su `README.md` (cómo usarla) y su `BITACORA.md` (qué se hizo y qué falta).
